# V2Sim 核心符号人工复核记录

本记录固定 V2Sim `v1.4.4`（commit `5cf6777ac6780f2247802533941204e4a95bc2ce`）。复核目标是确认本周案例复现和后续适配会直接触达的场景加载、时间推进、车辆/交通、充电、配网插件、控制与结果输出边界；它不证明新系统已经实现这些能力。

## 复核范围

| 类别 | 人工复核重点 | 开发边界 |
| --- | --- | --- |
| 仿真装配 | `V2SimInstance`、案例装配、start/step/stop/simulate/save | 可参考生命周期，不直接成为新系统编排 API |
| 案例与交通 | `CaseData`、`TimeConfig`、`TrafficInst` 的启动、推进和停止 | 输入 Schema、时间语义和错误契约需由新系统独立定义 |
| 车辆与充电 | `EV`、`CS`、`CSHub` 的充电、放电、队列和功率更新 | 可参考状态机；智能体动作仍须先通过新系统安全校验 |
| 插件与配网 | `PluginBase`、`PluginMan`、`PluginPDN` | FPowerKit 是 V2Sim 内部候选实现，不是已选主内核 |
| 结果 | `StaWriter`、`StaReader` | 可参考结果分类；归档、哈希和回放格式需重新设计 |

逐符号人工摘要保存在 `manual_review_summaries.tsv`，生成器将其写入 `symbols.csv` 和模块页并标记为“人工复核”。

## 模块抽检

对车辆生成、路网、结果读取、分段函数、行程日志、充电/车辆/配网统计和车辆字典模块执行字段抽检。抽检确认限定名、签名、源码锚点、输入输出、副作用、依赖、开发用途和复核状态均非空，不将静态检查升级为 E2/E3。
