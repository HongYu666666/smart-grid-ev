# gen/ — 数据生成模块

> 复核状态：抽检 [sampled]

## 核心类

| 符号 | 功能 | 说明 |
|------|------|------|
| TrafficGenerator | 行程生成器 | 生成车辆出行行程数据 |

## 关键方法

| 方法 | 功能 | 对应命令行工具 |
|------|------|--------------|
| VTrips() | 生成车辆行程 | v2sim-gen-trip |
| VTripsFromArgs() | 从命令行参数生成行程 | v2sim-gen-trip |

## 参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| n-ev | 电动汽车数量 | 必填 |
| n-gv | 普通车数量 | 必填 |
| day | 模拟天数 | 7 |
| seed | 随机种子 | 当前时间 |
| v | V2G 参与比例 | 1.0 |
| mode | 生成模式 (auto/node/taz/poly) | auto |
