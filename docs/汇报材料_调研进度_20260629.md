## 1. 调研结论摘要

本轮调研目标：确认"车-路-站-网世界模型"的可落地技术路线，并识别可复用的开源基础。

**核心结论：**
- 世界模型定义已明确：不是生成式神经网络模型，而是**可持续运行的联合仿真环境**，支持智能体可插拔接入。
- 技术路线选定：**阶段一** 自研 Python 内核（已有可运行原型）→ **阶段二** 接入 SUMO + pandapower → **阶段三** HELICS 联邦化。
- 发现高质量开源起点：**V2Sim**（东南大学，IEEE TSG 2025 发表），可显著降低阶段一/二的重复建设工作量。

## 3. V2Sim 开源平台评估

**来源：** [hesl-seu/v2sim](https://github.com/hesl-seu/v2sim)，东南大学 HESL 实验室

**论文：** V2Sim: An Open-Source Microscopic V2G Simulation Platform in Urban Power and Transportation Network，IEEE Transactions on Smart Grid，2025，Vol.16 No.4

**核心能力：**
- 支持 SUMO（微观交通）和 UXsim（轻量交通）两种后端，可切换
- EV 行为建模：出行目的地、SOC 演化、充电决策、V2G 放电
- 充电站队列与桩位管理
- 与交通网、配网联合仿真
- 提供 GUI 和 case 配置机制，可快速替换场景参数
- BSD 开源协议，可商用/科研改造

**与现有原型的差距：**

| 能力 | 我方现有原型 | V2Sim |
|---|---|---|
| 交通仿真 | 32 节点聚合流量（近似） | SUMO 微观 / UXsim |
| 配网潮流 | 筛查级近似模型 | 可接 pandapower（需扩展） |
| EV 行为 | 固定 Markov + SOC 阈值 | 概率行为表 + 出行目的地 |
| 充电站 | 简化队列 | 精细离散事件 |
| GUI | Web 沙盘（REST API） | 内置 GUI |
| V2G | 未实现 | 已实现 |

**复用策略：**
- 保留我方已有的**世界时钟、状态快照、事件注入、REST API 和 Web 沙盘**（V2Sim 不具备）
- 用 V2Sim 的 EV 行为模型和充电站模型替换现有近似实现
- 阶段二配网潮流通过 V2Sim 的扩展接口接入 pandapower

## 6. 当前主要阻塞

1. **原始数据缺口**：`ev_charging_v1/` 中有 `.npy/.xlsx` 历史数据，但 24 节点配网完整工程参数（额定电压、线路容量、变压器参数）尚不完整，接入 pandapower 前需补齐。
2. **V2Sim 适配边界**：V2Sim 内置案例基于简化路网，需要确认与现有 32 节点交通拓扑的映射成本。
3. **接口规范待定**：世界模型与孪生体、智能体的统一状态/动作接口尚未形成正式规范文档。
