# Issue #25 网页评审信息清单

> 使用者入口：首次查看 `v0.1 experimental` EV 单步架构验证结果。JSON/清单是事实源，网页只是只读投影；数据为固定 `demo/synthetic`，不是参考项目运行结果，也不是潮流或完整电气安全证明。

## 1. 系统模块

| 评审问题 | 新原型应展示 | 参考项目边界 | 未实现能力 |
| --- | --- | --- | --- |
| 系统由谁负责什么？ | 14 项责任及 `modules[].id/kind/responsibility/status`；区分 `reusable_core`、`replaceable_domain`、`replaceable_adapter` | `ev_charging_v1`、V2Sim 只可参考字段、单位、范围和页面表达，不得标为新系统能力或证据 | `external-adapters=unavailable`；正式系统包尚未建立 |
| 如何装配？ | 显式能力注册，展示 `provides/consumes/depends_on` 和唯一责任边界 | 不导入参考运行时对象，不复制其完成状态 | 真实配网、交通、方法和存储适配尚未接入 |

## 2. 正常、拒绝、降级运行流程

| 路径 | 使用者应看到 | 判读边界 |
| --- | --- | --- |
| 正常 | 读取 step 0 事实 → 快照 → 动作提议 → 合同/说明性容量校验 → 统一提交 → step 1 → 证据；动作生命周期为 `proposed → accepted → executing → executed` | 仅证明固定示例的合同、拒绝路径和提交语义 |
| 拒绝 | 动作生命周期为 `proposed → rejected`；显示 `decision.reason_code/message/safe_state`；step 1 事实与 step 0 相同 | 拒绝不得被解释为潮流计算或完整电气安全结论 |
| 降级 | 非关键能力为 `planned/unavailable/not_applicable` 时，保留原因并允许核心示例继续；网页失败时 JSON 事实仍有效，评审能力标为 `degraded` | 不得用空值或绿色完成标记掩盖缺失；关键证据缺失不得算 accepted success |

## 3. 运行身份、状态、动作、错误与证据字段

| 信息组 | 必看字段 |
| --- | --- |
| 运行身份 | `schema_version`、`message_type`、`run_id`、`scenario_id`、`scenario_version`、`step_index`、`sim_time`、`step_seconds`、`random_seed`、`producer` |
| 来源与质量 | `source.kind/input_path/input_sha256`、`quality.status/notes`；明确 `demo/synthetic` |
| 状态与快照 | `status`、`snapshots.before/after.version`、`grid_id/capacity_kw/base_load_kw/total_load_kw/headroom_kw`、`ev_fleet_id/ev_load_kw` |
| 动作与决定 | `action_id/action_type/target_id/proposer/snapshot_version/parameters/lifecycle`、`decision.rule_id/outcome/reason_code/message/safe_state` |
| 错误与证据 | `errors[].code/field/message/retryable/safe_state`；`evidence[].evidence_id/kind/sha256`，并用 `source.input_sha256` 回查输入证据 |

## 4. 能力状态与差距优先级

| 状态/优先级 | 使用者判读方式 | 当前关键差距 |
| --- | --- | --- |
| `demo_bound` | 仅在固定示例边界内已有证据，不等于正式系统完成 | 多数核心责任和三个领域孪生仅完成演示绑定 |
| `planned` / `unavailable` / `not_applicable` | 分别表示已登记待实现、外部能力不可用、本场景明确不需要 | 不得据此推导未提供结果 |
| `blocking` | 不解决就不能提升为正式能力 | 正式系统包；真实配网安全/潮流能力 |
| `important` | 架构稳定前必须补齐 | 第二场景集成门槛；完整 JSON Schema 验证器 |
| `planned` | 后续排期，不阻塞本次只读演示 | 方法接口映射；交互式 Web 服务本周不适用 |
