## 字段说明

| 字段 | 含义 |
|------|------|
| requirement_id | 稳定需求标识，REQ-EV-001 起编 |
| source | 需求来源（任务书条款/正式计划/批准决策） |
| scenario_step | 业务流程步骤或异常流程 |
| input_state | 输入数据和孪生体状态 |
| twin_responsibility | 孪生体负责的物理状态、演化和校验 |
| agent_responsibility | 智能体负责的感知、预测、建议或动作提案 |
| action_event | 控制动作或外部事件 |
| constraint | 物理、安全、数据或业务约束 |
| metric | 可计算评价指标 |
| evidence | 测试、数据、接口、演示或文档证据 |
| status | 已验证 / 部分具备 / 规划中 / 待裁定 |

## 关键发现

1. **孪生体基座稳固**：所有涉及确定性物理状态管理的需求（路径计算、充电仿真、潮流、电压校验）均已验证通过
2. **智能体为主要实现缺口**：6条规划中需求全部集中在 AI 模型实现（DRL/Informer/ST-GCN/BNN/闭环/评估）
3. **不存在把确定性工具标为独立智能体的行**：所有确定性计算（潮流、充电功率、路径）明确标注为孪生体责任
4. **配电网主仿真内核选型不影响本映射**：无论最终选 pandapower 还是 OpenDSS，REQ-EV-009 的孪生体责任定义不变
