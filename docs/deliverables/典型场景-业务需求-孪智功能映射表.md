## 2. 使用边界

- 孪生体负责事实状态、确定性演化和约束校验；智能体负责感知、预测、建议和动作提案。智能体不能直接改写孪生体状态。
- `precomputed_forecast_tool`、`static_policy_tool`、查表、回放、潮流计算器和确定性校验器均属于工具/模型组件，不是独立智能体。
- `root_step_check` 中“提案 accepted”目前只表示通过 `TwinStateValidator` 的基础结构检查，不表示动作已经执行，更不表示潮流、电压、设备载流或通信约束已经通过。
- 状态仅使用四类：`已验证` 表示已有可重复执行证据；`部分具备` 表示只有部分链路或代码资产；`规划中` 表示已批准但尚无实现证据；`待裁定` 表示本 change 明确留给后续决策。
