## 2. 场景业务流程

### 2.1 场景定义

电动汽车承载力提升场景研究的核心问题：在城市配电网中，大规模 EV 充电负荷接入后如何保证电网安全运行、提升 EV 接纳能力。

### 2.2 业务全流程

```
EV出行产生 → 充电需求触发 → 充电站选择决策 → 排队/充电过程 → 负荷接入配电网
      ↑                                                          │
      └──────────── 动态电价/拥堵反馈 ←──────────────────────────────┘
```

### 2.3 业务对象清单

| 序号 | 业务对象 | 描述 | 关键属性 |
|------|---------|------|---------|
| OBJ-1 | 电动汽车 | EV 车辆实体 | 位置、SOC、电池容量、行驶状态、人群类别 |
| OBJ-2 | 交通路网 | 城市道路拓扑 | 节点、有向路段、时变交通流、OD 矩阵 |
| OBJ-3 | 充电站 | EV 充电设施 | 站点位置、快/慢充桩数量、排队队列 |
| OBJ-4 | 配电网 | 电力分配网络 | 节点、线路阻抗、基础负荷、分布式资源 |
| OBJ-5 | 动态电价 | 基于电压偏移的定价 | 分时电价 + 实时调整 |
| OBJ-6 | 交通流 | 路段车辆流量 | 时间分辨率、流量矩阵 |

### 2.4 控制动作

| 动作 | 执行者 | 约束条件 |
|------|--------|---------|
| 充电站选择 | 智能体/用户 | SOC 可达性、排队长度、电价 |
| 充电模式选择 | 智能体 | 快充/慢充、目标 SOC、可用时间 |
| 动态电价调整 | 配电网侧 | 电压偏移约束、公平性 |
| V2G 放电 | 智能体 | SOC 下限、用户意愿、电网需求 |
| 充电功率调节 | 充电站 | 变压器容量、电压安全 |

### 2.5 物理与业务约束

| 约束类型 | 具体约束 |
|---------|---------|
| 电池物理 | 0 ≤ SOC ≤ 1；充电功率曲线 P(SOC) |
| 电网安全 | 节点电压 0.95–1.05 p.u.；线路不过载 |
| 充电站容量 | 桩位数量上限 |
| 交通约束 | 行驶能耗与路况相关；时变最短路 |
| 用户行为 | 出行 OD 分布；充电时间偏好 |

### 2.6 评价指标

| 指标 | 含义 | 计算方式 |
|------|------|---------|
| EV 承载力 | 配电网可接纳的最大 EV 数量 | 逐步增加 EV 至电压越限 |
| 负荷峰谷比 | 充电负荷的峰谷差异 | (P_max − P_min) / P_avg |
| 电压偏移 | 节点电压偏离额定值 | max(\|V_i − 1.0\|) |
| 用户等待时间 | 充电排队等待时长 | 平均等待时间 |
| 负荷预测精度 | 预测与实际负荷偏差 | MAE, RMSE, R² |

### 2.7 异常情形

| 异常 | 影响 | 处置 |
|------|------|------|
| 充电站故障 | 车辆无法充电，负荷转移 | 引导至邻近站点 |
| 电压越限 | 配电网不安全运行 | 拒绝/削减充电负荷 |
| 极端天气 | 充电效率下降 | 温度-效率修正 |
| 交通拥堵 | 行驶能耗增大 | 路径重规划 |

### 3.3 V2Sim 开源平台（外部参考项目 — 摘要）

V2Sim（v1.4.4，BSD 许可，东南大学 hesl-seu）是一个开源 V2G 仿真平台。本报告仅记录摘要；完整代表性案例运行记录将作为 `assess-grid-simulation-backends` change 的独立成果提交至 `docs/deliverables/V2Sim典型案例运行记录.md`。

**摘要**：

- 平台地址：https://github.com/hesl-seu/v2sim ，版本 1.4.4
- 支持 UXsim（中观）和 SUMO（微观）两种交通引擎
- 包含 EV 充电/V2G/配电网（FPowerKit）仿真能力
- 提供 6 个示例案例（ux_12nodes, ux_37nodes, ux_Nanjing, sumo_12nodes, sumo_37nodes, sumo_Nanjing）
- 本地已完成 `ux_12nodes` 案例的初步运行确认（详见后续独立记录）

**注意**：V2Sim 的能力评估不在本 change 范围内，不用于提前决定交通仿真路线或配电网主仿真内核。

## 5. 数据缺口分析

| 数据需求 | 现有情况 | 缺口 |
|---------|---------|------|
| 真实 EV 充电记录 | 参考项目使用仿真数据 | 缺少真实运营数据标定 |
| 真实交通流 | 参考项目使用聚合模型 | 缺少大规模 OD 数据 |
| 配电网实测数据 | 参考项目使用 IEEE 算例 | 缺少真实拓扑与量测 |
| 气象数据 | 参考项目使用温度曲线插值 | 缺少实时气象 API |
| 电价政策 | 参考项目使用静态分时电价 | 缺少实时电力市场 |
