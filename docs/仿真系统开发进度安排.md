# 孪智融合配电系统运行仿真软件研发计划

更新日期：2026-07-09

技术基线：以 V2Sim 为基础仿真内核，复用其交通运行、电动汽车出行、充电站运行、配电网计算及统计分析能力，在此基础上构建面向课题业务的完整仿真系统。仿真系统负责统一组织数据、模型、时序、事件、状态、控制、指标、存储、回放和可视化，并为孪生体、智能体及业务应用提供标准交互接口。

## 研发计划
