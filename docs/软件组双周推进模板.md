# 软件组双周推进模板

适用范围：国重课题一软件组双周例会、阶段汇报、组内进度收敛。

建议每位成员控制在 150-230 字，避免只写“学习、调研、开发中”。每条进展都要尽量落到任务书条款、软件模块、接口、数据、指标或演示结果。

## 1. 基本信息

| 项目 | 内容 |
| --- | --- |
| 汇报周期 | 例如：2026-06-24 至 2026-07-08 |
| 汇报人 |  |
| 负责方向 | 例如：世界模型 / 后端接口 / 前端可视化 / 业务流程 / 智能体 |
| 对应任务书内容 |  |
| 对应软件版本 | 例如：v0.1 / v0.2 / 半年度演示版 |

## 2. 本周期完成进展

要求：说明做了什么，支撑哪个业务或模块，形成什么可检查结果。

示例：

> 完成电动汽车承载力提升场景下充电站、车辆出行、SOC、排队状态和配网节点负载的基础状态建模，已接入世界模型时序驱动流程。当前可生成连续 7 天仿真记录，并输出站点负载、排队长度、用户满意度等指标。

## 4. 当前困难

要求：30-80 字，写清楚阻塞点和需要谁协助。

示例：

> 配网潮流计算输入字段尚未统一，导致世界模型输出与后续安全校验模块无法直接对接。需要配网建模方向确认节点、线路、设备状态字段。

填写：

## 5. 下半月计划

要求：30-80 字，明确下一个可验收结果，不写泛泛“继续完善”。

示例：

> 下半月完成状态-动作-事件统一接口第一版，并将电动汽车场景的充电调度动作接入前端演示，形成可回放的端到端闭环。
